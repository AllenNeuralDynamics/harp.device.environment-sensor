# harp-env-sensor

Python interface for the Harp Environment Sensor device.

The package in `src/harp/device/environment_sensor` is generated from [`device.yml`](../../device.yml). Do not edit it by hand; regenerate it with `bash software/regenerate.sh`.

## Examples

Example scripts are in [examples](examples): `read_once.py`, `read_continuously.py` and `read_events.py`. Each takes `--port` (and optionally `--file` to save a csv).
